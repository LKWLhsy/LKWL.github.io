本隐私政策说明访问本站时可能涉及的信息处理方式。本站是由个人维护的静态博客，不提供账户注册或登录功能，也不会主动要求访客提供真实姓名、身份证件、住址或支付信息。

## 网站托管

本站使用 Hugo 生成静态页面，并通过 GitHub Pages 托管。访问本站时，请求会经过 GitHub 提供的基础设施；GitHub 可能按照其自身政策处理访问日志、IP 地址、浏览器信息和安全诊断数据。

相关数据的具体处理方式以 [GitHub 隐私声明](https://docs.github.com/zh/site-policy/privacy-policies/github-general-privacy-statement) 为准。

## 评论与浏览量

本站使用 Waline 提供评论和浏览量功能。当前 Waline 服务地址为第三方演示服务，并非由本站自行托管。

当你发表评论时，Waline 可能处理你主动填写的昵称、邮箱、个人网站和评论内容，也可能处理 IP 地址、浏览器类型等为提供服务、安全防护或反垃圾评论所需的技术信息。邮箱通常用于头像或回复通知，是否填写取决于评论组件的实际要求。

请不要在评论中提交密码、身份证件、电话号码、住址、未公开研究数据或其他敏感信息。如需删除或更正本站展示的评论，可以通过本政策末尾的联系方式提出请求；第三方服务中的数据处理和保留仍受服务提供方能力与政策限制。

## 浏览器本地存储与 Cookie

Stack 主题使用浏览器的 `localStorage` 保存明暗模式偏好，使页面在后续访问时保持你选择的显示方式。这项数据保存在你的浏览器中，本站不会通过该设置识别你的真实身份。

本站目前没有启用 Stack 的 Cookie 同意横幅，也没有配置 Google Analytics。Waline 或其他第三方资源可能根据其自身实现使用 Cookie 或本地存储；你可以通过浏览器设置查看、限制或清除这些数据。

## 外部资源

本站的部分页面可能从第三方服务加载字体、脚本、样式、图片或表情资源，包括 Google Fonts、unpkg 和 jsDelivr。启用数学公式、图集、流程图或评论功能的页面还可能请求 KaTeX、PhotoSwipe、Mermaid 或 Waline 相关资源。

连接这些服务时，服务提供方通常会接收到完成网络请求所需的 IP 地址、浏览器信息、请求时间和来源页面等技术数据。相关处理受各服务提供方自己的隐私政策约束。

## 外部链接

文章中可能包含指向其他网站的链接。离开本站后，目标网站如何收集和使用信息不受本站控制，请在提交个人信息前阅读目标网站的隐私说明。

## 数据出售、广告与分析

本站目前不出售访客个人信息，也没有接入 Google AdSense 或其他广告平台，并且没有配置 Google Analytics。若未来增加广告、统计分析、独立评论服务或其他可能改变数据处理方式的功能，本政策将相应更新。

## 政策更新

本站可能因功能、托管方式或第三方服务变化而更新本政策。更新后的内容将在本页面发布，并修改页面中的最后更新时间。
